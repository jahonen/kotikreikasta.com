
# Admin Section: Integrated CMS and CRM Specification

## 1. Overview
The Admin Section is divided into two integrated sub-sections:
- **CMS (Content Management System):** Manages property listings and blog posts, optimized for SEO and multi-channel publishing.
- **CRM (Customer Relationship Management):** Tracks user interactions, inquiries, and referral sources to measure channel effectiveness and revenue generation.

The system leverages Firebase for data storage, Google Cloud for infrastructure, Vertex AI for content optimization, and Google Secret Manager for secure API key management.

### 2.2 Content Authoring and AI Enhancement
- **Editor Interface:**
  - Rich-text editor for both Listing and Blog Post modes.
  - Vertex AI auto-generates:
    - Summaries
    - SEO Titles
    - Meta Descriptions
    - Alt Text for media files

- **Media Handling:**
  - Images and videos uploaded to Firebase Storage.
  - Alt text auto-generated by Vertex AI for SEO compliance.

---

### 2.3 URL Generation
- **Long Format:** `https://kotikreikasta.com/[type]/[stub]`
- **Short Format with Referral Code:** `https://kotikreikasta.com/c/[stub]?ref=[referral_code]`
  - Example: `https://kotikreikasta.com/c/beachfront-villa-athens?ref=twitter`

---

### 2.4 Publication Queue
- **Purpose:** Staging area for content before distribution.
- **Data Structure:**

| Field                | Type         | Description                          |
|----------------------|--------------|--------------------------------------|
| id                   | String       | Unique identifier                    |
| contentType          | String       | "Listing" or "Blog Post"             |
| contentId            | String       | Reference to listing/blog_post ID    |
| shortUrl             | String       | Short URL for the content            |
| referralCodes        | Array        | List of referral codes for platforms |
| status               | String       | Publication status                   |
| createdAt            | Timestamp    | Creation timestamp                   |
| updatedAt            | Timestamp    | Last update timestamp                |
| scheduledFor         | Timestamp    | Scheduled publication time           |

---

### 2.5 Content Distribution Consumers
- **Platforms:**
  - X (Twitter): `ref=twitter`
  - Bluesky: `ref=bluesky`
  - Threads: `ref=threads`
  - Facebook: `ref=facebook`
  - Email: `ref=email`

- **Consumer Logic:**
  - Fetches content from the queue.
  - Appends platform-specific referral code to the short URL.
  - Publishes via platform APIs (SendGrid for email).

## 3. CRM (Customer Relationship Management)

### 3.1 User Interaction Tracking
- **Referral Tracking:**
  - When a user clicks a referral URL, the `ref` code is captured and stored in a cookie/session.
  - If the user contacts the agency or subscribes to a newsletter, the referral code is logged in the `user_referrals` collection.

## 4. Integration Between CMS and CRM

### 4.1 Data Flow
1. **Content Creation:**
   - Admin creates a Listing/Blog Post in the CMS.
   - Vertex AI generates SEO-optimized content.
   - Content is saved to Firebase with a URL stub.

2. **Publication:**
   - Content and short URL are pushed to the publication queue with referral codes.
   - Consumers publish content to platforms with referral-coded URLs.

3. **User Interaction:**
   - User clicks a referral URL and contacts the agency or subscribes to a newsletter.
   - Referral code is logged in `user_referrals` and linked to the inquiry or subscription.

4. **Analytics:**
   - Dashboard aggregates data to show revenue, inquiries, and subscriptions by referral code.

## 6. Workflow Diagram

```plaintext
1. Admin creates content (Listing/Blog Post) in CMS.
2. Vertex AI generates summaries, SEO titles, meta descriptions, and alt texts.
3. Content is saved to Firebase with a URL stub.
4. Content and short URL are pushed to the publication queue with referral codes.
5. Consumers fetch content, append referral codes, and publish to platforms.
6. User clicks referral URL and contacts the agency or subscribes to a newsletter.
7. Referral code is logged in `user_referrals` and linked to the inquiry or subscription.
8. Analytics dashboard tracks inquiries, subscriptions, and revenue by referral code.
```
